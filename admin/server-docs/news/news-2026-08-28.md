## A networking library with an unexpectedly complicated integration path

The move to **curl 8.21.0** was significant because it tied together networking, TLS, the build graph and installed-consumer tests. The commits record a staged curl contract, separate installed-consumer smoke definition, SHA-pinned source archive, and several attempts to automate the one-shot source pin or integration process.

That automation was not a straight line: helper scripts and a contract fragment were subsequently removed or replaced. This matters because a successful source download is not yet a passing binary consumer; the installed import library, DLL dependencies and selected variant must be tested.

## Compression dependencies and variant boundaries

**XZ** was brought into the **libarchive** dependency structure, while shared-library output was reinforced as the target product mode. The zlib consumer smoke also needed variant-specific link corrections.

The number of small repairs is itself part of the history. They show why dependencies, source pins, runtime layout and test stages could not remain informal shell or IDE knowledge.

## Last native gates: CGAL and OpenAL Soft

The supplied FSM transcript showed **140 finished / 141 total**, with CGAL 6.2.1 reaching `ready PASS` after its Release and Debug consumer smokes (`15.1s` and `22.9s`). Only OpenAL Soft remained blocked at `publish`. The collision named `include/gmock/gmock-actions.h`, an installed GoogleMock header outside the public OpenAL API.

The OpenAL producer's upstream tests, audio backends, utilities, Debug/Release builds and installed-package smoke were retained. The publication contract now maps `include/AL`, selected native OpenAL import-library names, `OpenAL32.dll` and optional OpenAL CMake exports into the shared consumer SDK; GoogleTest/GoogleMock installed test components stay in the producer package rather than being republished as OpenAL-owned public API. The generic `files` operation supports declarative `names` matching and the CMake forwarder supports `prefixes` matching, both documented in Schema 17. This is an SDK projection change, **not** an upstream producer or test suppression.

BuildEngine's logical FSM current-state contract remains timestamp and direct upstream completion evidence. Artifact inventory and publish manifests remain separate evidence; no library timestamp was changed to force a rebuild. The operator subsequently reported successful completion of the remaining work.

## The seven-library showcase expedition

Three independent native C++23 showcases have been committed to `BuildEngine-Tests`, each with a CMake project, source, headless `--verify`, `Description.md`, `build.md`, `showcase.json`, a dedicated gallery SVG tile and a separately labelled conceptual desktop-window SVG:

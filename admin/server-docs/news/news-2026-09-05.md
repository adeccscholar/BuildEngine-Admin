## Skia integration: removing workarounds without losing compatibility

The Skia work exposed an uncomfortable integration problem: compiler, linker, archiver, Python and UCRT wrapper scripts were being removed or replaced, while BCC64X still required explicit Windows x64 library paths and a version-bound GN patch. Some cleanup was reverted because the staging was incomplete.

The commit history is notably iterative. Several Skia repair commits and a rollback appear on the same day. That is useful history: removing wrappers may simplify maintenance, but it must not silently remove linker assumptions required by the installed artifacts.

GoogleTest and Markdown tooling were also present in the day's integration work. The purpose of this record is to capture the repairs and rollback rather than rewrite them as an uninterrupted success story.

## Restore the BCC64X baseline before changing more libraries

The CMake toolchain was explicitly restored to a proven BCC64X baseline. At the same time, the active ICU VCXPROJ bootstrap path was documented in a series of commits.

The combination illustrates a recurring difficulty with a mixed upstream ecosystem: some dependencies require project-specific build entry points, while all must still satisfy the same native Windows x64 compiler and runtime contract. Restoring a known toolchain baseline is a regression-control action, not proof that every dependent package is passing.

**Evidence:** [BCC64X CMake baseline](https://github.com/adeccscholar/BuildEngine-Admin/commit/434f5b8ef), [ICU VCXPROJ bootstrap documentation](https://github.com/adeccscholar/BuildEngine-Admin/commit/d28791bff).

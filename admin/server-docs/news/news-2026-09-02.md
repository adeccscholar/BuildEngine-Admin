## Bringing bootstrap tools under management

Two new source bootstrap paths were documented and added: Meson and Python. Meson supports upstream projects whose primary configuration is not CMake; a managed Python path supports build generators and supporting tools without relying on a mutable global Python installation.

These additions were about dependency control, not expanding the list of runtime DLLs. A library built with Ninja can still depend on Python or Meson during preparation, so both tools belong in the reproducibility story.

**Evidence:** [reproducible Meson source bootstrap](https://github.com/adeccscholar/BuildEngine-Admin/commit/3bde8f741), [managed Python bootstrap](https://github.com/adeccscholar/BuildEngine-Admin/commit/4eb28580c).

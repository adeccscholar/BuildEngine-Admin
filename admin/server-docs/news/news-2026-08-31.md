# BuildEngine News — 2026-08-31: Xerces, documentation, licensing and ACE/TAO

[TOC|Content]

## XML and C++ ABI integration

The Xerces-C 3.3.0 BCC64X contract came with DOM and installed-consumer smoke registrations. Its `HandlerBase` vtable behavior required multiple patch and rebuild corrections; the commit sequence also isolated a Release `ThreadTest` link failure. These records explain why a versioned patch must be checked against the exact upstream source state, not simply retained because it once applied.

## Documentation and provenance become first-class work

The same day introduced **portable Doxygen 1.18.0**, parallel Xerces documentation, and schema changes for versioned license metadata, cumulative license reporting, and SBOM integration. This extended the workflow from compilation into evidence that downstream users and auditors can actually inspect.

## ACE/TAO expands the problem space

A series of ACE/TAO commits added Win64 backports, SSLIOP adaptations, package installation and BMake-specific library-name corrections. Complex middleware was useful precisely because it exercised a different build system and deeper runtime relationships than the early pugiXML experiment.

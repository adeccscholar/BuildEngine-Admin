## Graphviz enters the documentation toolchain

Graphviz became a managed documentation tool, supporting generated dependency diagrams rather than relying on arbitrary local installations. This is significant for BuildEngine because the library catalog is a graph: visualizing transitive dependencies helps expose accidental version drift and unexpected coupling.

A subsequent commit explicitly finalized the Graphviz toolchain and restored existing version pins. Keeping the pins intact matters more than an attractive visualization: documentation generation must not modify the package selection it is supposed to describe.

**Evidence:** [managed Graphviz](https://github.com/adeccscholar/BuildEngine-Admin/commit/013a4ca70), [toolchain and pin restoration](https://github.com/adeccscholar/BuildEngine-Admin/commit/827c450e6).

**Evidence status:** Toolchain changes confirmed by Git; rendered documentation outcome not asserted.

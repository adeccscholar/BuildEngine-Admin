# BuildEngine News — 2026-11-17

## Safe live-catalog optimization

- BuildEngine-Common now compares the complete bytes of `admin/build-libraries.xml` on catalog access, caches the validated parsed catalog by production path and reparses only when content changes. Changes with identical file size or timestamps are detected.
- A read or parse failure is reported rather than silently serving an obsolete catalog. Installed package and SBOM status remain live and are not frozen in the catalog snapshot.
- No HTTP thread pool, new background worker, or cross-request package cache has been introduced. This is the limited, measurable first optimization step, keeping the existing Server/Common responsibility boundary.
- **[not verified]** Native BCC64X compilation, live-update regression and latency benchmark are pending.

## SDL3 and Box2D package registration

- Registered SDL3 3.4.20 and Box2D 3.2.0 as independent native BCC64X DLL producers with versioned sources, dynamic runtime policy, Debug/Release install gates, licensing, package descriptions, CMake consumer definitions and separate smoke programs.
- SDL2 2.32.10 remains unchanged and installed alongside SDL3. Both projects retain their respective original APIs without invented C/C++ compatibility wrappers.
- The adapters disable auxiliary upstream samples/tests for the production builds. Native BCC64X compilation, install and smoke are **[not verified]** and must not be described as successful.
- **Declared catalog: 81 distinct libraries / 116 versioned integrations** (previously 79 / 114).

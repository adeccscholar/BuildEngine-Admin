# LLVM OpenMP runtime 20.1.7 / BCC64X migration
\brief Preliminary integration of upstream LLVM libomp into the BuildEngine package lifecycle.

Source is pinned to LLVM release tag llvmorg-20.1.7 (commit 6146a88f60492b520a36f8f8f3231e15f3cc6082). Use standalone openmp source, never build the entire LLVM/Clang toolchain or silently select the vendor's runtime.

The original zero-download openmp-probe completed nine extended checks successfully on 2026-10-22; it printed "DLL name not identified", so it did not establish runtime ownership. These checks are preserved in the new library consumer, but the new consumer demands package-local omp.h, import library and libomp.dll.

The initial XML integration is intentionally subject to the Windows/BCC64X configure/build evidence; never classify it PASS from source inspection. In particular, confirm the runtime import-library filename generated by upstream CMake, the LLVM OpenMP MASM/DEF generation path, installed artifacts for both configurations, and the actual DLL resolved by the Windows loader. No fallback to toolchain libomp is acceptable.
